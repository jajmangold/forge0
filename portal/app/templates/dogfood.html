How a run stays bounded

Publication stops at a draft pull request
  • Requires the {{ config.trigger_label }} label
  • Requires explicit acceptance criteria
  • Works in a disposable repository clone
  • Runs fixed operator-owned checks
  • Applies file, diff, context, and token limits
  • Never merges or deploys automatically

Manual trigger

After preparing and labeling an issue, an operator can start it through the authenticated endpoint:

curl -X POST \
  -H "X-Forge0-Operator-Token: $FORGE0_OPERATOR_TOKEN" \
  http://localhost:3001/api/dogfood/run/{{ config.self_owner }}/{{ config.self_repo }}/ISSUE
